# NHT Operations Dashboard — V1

Browser-only dashboard for the NHT summary Excel.

## How to use
1. Open `index.html` in a browser.
2. Click **Upload NHT Excel**.
3. Select the latest NHT summary workbook.
4. Use Month and Location filters.
5. Charts and KPIs redraw automatically.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a repository and enable GitHub Pages.

## Data privacy
The workbook is read locally in the browser. The Excel file is not written into the repository by this dashboard.

## Important
V1 is built around the summary structure supplied for this project. Before production use, verify the calculated KPI definitions against your company's official formulas, especially throughput and joining throughput.
